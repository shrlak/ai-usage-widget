# 📊 AI 사용량 위젯

**Claude Code**와 **Codex**의 남은 사용 한도, 오늘 쓴 토큰, 지금 돌아가는 세션을 화면 한쪽에 작게 띄워 두는 위젯이에요.
항상 모든 창 위에 떠 있고(전체 화면 앱 위에도), 마우스로 끌어서 원하는 곳으로 옮길 수 있어요. 옮긴 위치는 기억해요.

- **남은 한도**: 5시간 · 주간 한도가 몇 % 남았는지, 언제 초기화되는지
- **오늘 토큰**: 자정부터 쓴 토큰 (입력 · 출력 · 캐시)
- **실행 현황**: 지금 어떤 프로젝트에서 무엇을 하는지 (명령 실행 중, 파일 수정 중, 답변 대기, 승인 요청 …) + 대화(컨텍스트)를 몇 % 썼는지

토큰을 쓰지 않아요. 내 컴퓨터에 남는 기록 파일(`~/.claude/projects`, `~/.codex/sessions`)을 **읽기만** 하고, 인터넷으로 아무것도 보내지 않아요.

---

## 🚀 설치와 실행

**준비물**: [Node.js](https://nodejs.org/ko) 18 이상 (`node -v` 로 확인)

```bash
cd ai-usage-widget      # 압축을 푼 폴더
npm install             # 처음 한 번 (Electron 을 내려받아요, 1~2분)
npm start               # 위젯 실행
```

화면 오른쪽 위에 위젯이 떠요. 끄려면 메뉴(⋯)에서 **종료**를 누르세요.

### Claude 남은 한도 연결 (처음 한 번)

Claude Code는 남은 한도를 기록 파일에 남기지 않고 **상태줄(statusLine)** 명령에만 알려줘요.
그래서 위젯의 Claude 칸에 있는 **연결하기** 버튼을 한 번 눌러야 해요.

- `~/.claude/settings.json` 의 `statusLine` 을 위젯 것으로 바꿔요. 원래 파일은 `settings.json.before-ai-usage-widget` 로 백업해요
- 이미 쓰던 상태줄(예: 클로드 오피스)이 있으면 **그대로 실행**해 줘서 터미널 화면은 똑같아요
- 연결한 뒤 **Claude Code를 다시 켜고 한 번 대화**하면 숫자가 나와요 (Pro · Max 요금제)
- 메뉴 → **Claude 한도 연결 해제**를 누르면 원래대로 돌아가요

Codex는 기록 파일에 한도가 들어 있어서 따로 할 게 없어요.

## 🖱 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 위치 옮기기 | 위젯 아무 곳이나 잡고 끌기 |
| 작게 / 크게 | 오른쪽 위 **–** / **+** 버튼 (작게 보면 한 줄로 `Claude 62%/19%  Codex 88%/65%`) |
| 메뉴 | **⋯** 버튼, 위젯에서 오른쪽 클릭, 또는 메뉴 막대(트레이) 아이콘 |
| 숨기기 / 보이기 | `⌘ + ⌥ + U` (Windows `Ctrl + Alt + U`), 또는 메뉴 |
| 투명도 | 메뉴 → 투명도 (100% ~ 60%) |
| 항상 위에 끄기 | 메뉴 → 항상 맨 위에 |
| 세션 목록 숨기기 | 메뉴 → 세션 목록 보이기 |
| 위치 초기화 | 메뉴 → 위치 처음대로 |

### 숫자 읽는 법

- 막대와 **%는 남은 양**이에요 (배터리처럼 줄어들어요). 30% 아래는 주황, 10% 아래는 빨강
- `31분 전` 태그: 한도 정보를 마지막으로 받은 시각이에요. Claude는 Claude Code를 쓰는 동안, Codex는 Codex를 쓰는 동안 새로 받아요
- 세션 줄의 점: 🟢 깜빡임 = 작업 중, 🟠 = 질문 · 승인 요청, 🔵 = 답변 끝나고 대기, ⚪ = 조용함
- `C` = Claude Code, `X` = Codex · `대화 41%` = 그 세션의 대화 길이(컨텍스트) 사용량

## 📦 진짜 앱으로 만들기 (선택)

`npm start` 대신 더블클릭으로 켜는 앱을 만들 수 있어요.

```bash
npm run dist
```

- **Mac**: `dist/` 안의 `.dmg` 를 열어 응용 프로그램 폴더로 끌어다 놓기. 서명이 없는 앱이라 처음엔 **오른쪽 클릭 → 열기**로 켜야 해요
- **Windows**: `dist/` 안의 설치 파일(`.exe`) 실행

앱으로 설치하면 메뉴의 **로그인할 때 자동 실행**을 켤 수 있어요. 컴퓨터를 켤 때마다 위젯이 자동으로 떠요.

## ❓ 자주 묻는 질문

**Claude 칸에 "한 번 대화하면 …"만 나와요**
연결 후 Claude Code를 완전히 껐다 켜고 아무 말이나 한 번 해 보세요. 상태줄이 실행될 때 한도가 기록돼요.

**Mac에서 전체 화면 앱 위에 안 떠요**
메뉴에서 **항상 맨 위에**를 껐다 켜 보세요. 그래도 안 되면 위젯을 종료했다가 다시 켜세요.

**Windows에서 가끔 다른 창 밑으로 가요**
다른 창을 누르는 순간 위젯이 다시 맨 위로 올라와요. 게임처럼 독점 전체 화면을 쓰는 프로그램 위에는 뜨지 않아요.

**기록 폴더가 다른 곳에 있어요**
`CLAUDE_CONFIG_DIR=/경로 npm start`, `CODEX_HOME=/경로 npm start` 처럼 알려 주세요.

**완전히 지우고 싶어요**
메뉴에서 **Claude 한도 연결 해제** → 종료 → 이 폴더와 `~/.ai-usage-widget` 폴더 삭제.

## 🔍 파일

| 파일 | 역할 |
|---|---|
| `main.js` | 떠 있는 창, 위치 기억, 메뉴 · 트레이 |
| `collector.js` | Claude · Codex 기록을 읽어 한도 · 토큰 · 세션 상태 계산 |
| `claude-link.js` | Claude Code 상태줄 연결 / 해제 (백업 · 원래 상태줄 이어 실행) |
| `statusline.js` | Claude Code 상태줄. 받은 한도를 `~/.ai-usage-widget/claude-usage.json` 에 적음 |
| `renderer/` | 위젯 화면 |
