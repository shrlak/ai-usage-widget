# 📊 AI 사용량 위젯

**Claude**와 **Codex**의 남은 사용 한도, 오늘 쓴 토큰, 지금 돌아가는 세션을 화면 한쪽에 작게 띄워 두는 위젯이에요.
항상 모든 창 위에 떠 있고(전체 화면 앱 위에도), 마우스로 끌어서 원하는 곳으로 옮길 수 있어요. 옮긴 위치는 기억해요.

- **남은 한도**: 5시간 · 주간 한도가 몇 % 남았는지, 언제 초기화되는지
- **오늘 토큰**: 자정부터 쓴 토큰 (입력 · 출력 · 캐시)
- **실행 현황**: 지금 어떤 프로젝트에서 무엇을 하는지 (명령 실행 중, 파일 수정 중, 답변 대기, 승인 요청 …) + 대화(컨텍스트)를 몇 % 썼는지

터미널에서 쓰든 **데스크톱 앱**에서 쓰든 자동으로 보여요. 컴퓨터를 켜면 위젯도 알아서 떠요.

---

## 🚀 설치 (터미널 필요 없음)

1. 이 저장소의 **[Releases](../../releases/latest)** 에서 내 컴퓨터에 맞는 파일을 내려받아요
   - Mac (M1 · M2 · M3 · M4 …): `AI-Usage-Widget-…-mac-arm64.dmg`
   - Mac (Intel): `AI-Usage-Widget-…-mac-x64.dmg`
   - Windows: `AI-Usage-Widget-…-win-x64.exe`
2. 설치해요
   - **Mac**: `.dmg` 를 열고 **AI 사용량** 아이콘을 응용 프로그램 폴더로 끌어다 놓기 → 응용 프로그램에서 실행.
     처음엔 "확인할 수 없는 개발자" 경고가 떠요. **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누르세요 (한 번만)
   - **Windows**: `.exe` 실행. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
3. 끝! 화면 오른쪽 위에 위젯이 떠요. 다음부터는 **로그인할 때 자동으로** 떠요 (메뉴에서 끌 수 있어요)

> Mac에서 처음 켤 때 **"security이(가) 'Claude Code-credentials' 키체인을 사용하려고 합니다"** 창이 뜨면 로그인 암호를 넣고 **항상 허용**을 누르세요. Claude 남은 한도를 읽는 데 필요해요 (아래 설명).

## 🔢 숫자는 어디서 오나

| 항목 | Claude | Codex |
|---|---|---|
| 남은 한도 | Claude 계정에 직접 물어봄 (3분마다) | Codex 기록 파일 (`~/.codex/sessions`) |
| 오늘 토큰 · 실행 현황 | Claude Code 기록 파일 (`~/.claude/projects`) | Codex 기록 파일 |

- **Claude 남은 한도**: Claude Code에 로그인돼 있으면, 그 로그인 정보(`~/.claude/.credentials.json`, Mac은 키체인)로 Claude Code의 `/status` 와 같은 사용량 주소(`api.anthropic.com`)에 물어봐요. 로그인 정보는 Anthropic 서버에만 보내고 따로 저장하지 않아요.
  이 한도는 claude.ai · 데스크톱 앱 · Claude Code가 함께 쓰는 거라, 어디서 쓰든 숫자가 같이 줄어요
- 공식 문서가 없는 주소라 언젠가 바뀔 수 있어요. 그때는 메뉴의 **Claude 상태줄로도 받기…** 를 켜 두면 Claude Code를 쓸 때마다 상태줄이 한도를 받아 적어 줘요 (원래 `settings.json` 은 백업하고, 쓰던 상태줄은 그대로 보여요)
- 이 방법이 싫으면 메뉴에서 **Claude 한도를 계정에서 자동 확인**을 끄면 돼요
- 그 밖에는 기록 파일을 **읽기만** 해요. 토큰을 쓰지 않아요

## 🖱 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 위치 옮기기 | 위젯 아무 곳이나 잡고 끌기 |
| 작게 / 크게 | 오른쪽 위 **–** / **+** 버튼 (작게 보면 한 줄로 `Claude 62%/19%  Codex 88%/65%`) |
| 메뉴 | **⋯** 버튼, 위젯에서 오른쪽 클릭, 또는 메뉴 막대(트레이) 아이콘 |
| 숨기기 / 보이기 | `⌘ + ⌥ + U` (Windows `Ctrl + Alt + U`), 또는 메뉴 |
| 투명도 | 메뉴 → 투명도 (100% ~ 60%) |
| 항상 위에 끄기 | 메뉴 → 항상 맨 위에 |
| 자동 실행 끄기 | 메뉴 → 로그인할 때 자동 실행 |
| 위치 초기화 | 메뉴 → 위치 처음대로 |

### 숫자 읽는 법

- 막대와 **%는 남은 양**이에요 (배터리처럼 줄어들어요). 30% 아래는 주황, 10% 아래는 빨강
- `31분 전` 태그: 한도 정보를 마지막으로 받은 시각 (30분이 넘었을 때만 보여요)
- 세션 줄의 점: 🟢 깜빡임 = 작업 중, 🟠 = 질문 · 승인 요청, 🔵 = 답변 끝나고 대기, ⚪ = 조용함
- `C` = Claude Code, `X` = Codex · `대화 41%` = 그 세션의 대화 길이(컨텍스트) 사용량

## ❓ 자주 묻는 질문

**Claude 칸에 "로그인돼 있으면 자동으로 보여요"가 나와요**
이 컴퓨터에서 Claude Code 로그인 정보를 못 찾았어요. 데스크톱 앱의 Code 탭이나 터미널의 `claude` 에서 한 번 로그인한 뒤 메뉴 → **Claude 한도 지금 다시 확인**.

**"로그인이 만료됐어요"가 나와요**
Claude Code를 한동안 안 켜면 로그인 토큰이 만료돼요. Claude Code를 한 번 열면 새 토큰을 받아서 다시 보여요.

**데스크톱 앱에서 쓰는 세션이 목록에 안 보여요**
목록은 `~/.claude/projects` (Claude Code)와 `~/.codex/sessions` (Codex)에 남는 기록으로 만들어요. 데스크톱 앱의 일반 채팅은 이 기록을 남기지 않아서 목록엔 안 나와요. 한도 숫자에는 똑같이 반영돼요.

**Mac에서 전체 화면 앱 위에 안 떠요**
메뉴에서 **항상 맨 위에**를 껐다 켜 보세요. 그래도 안 되면 위젯을 종료했다가 다시 켜세요.

**Windows에서 가끔 다른 창 밑으로 가요**
다른 창을 누르는 순간 위젯이 다시 맨 위로 올라와요. 게임처럼 독점 전체 화면을 쓰는 프로그램 위에는 뜨지 않아요.

**완전히 지우고 싶어요**
메뉴에서 자동 실행 끄기 → (켜 뒀다면) 상태줄 연결 해제 → 종료 → 앱 삭제, `~/.ai-usage-widget` 폴더 삭제.

## 🛠 직접 실행 · 빌드 (개발용)

```bash
npm install
npm start          # 바로 실행
npm run dist       # 내 컴퓨터용 설치 파일을 dist/ 에 만들기
```

`v1.0.1` 처럼 `v` 로 시작하는 태그를 올리면 GitHub Actions(`.github/workflows/release.yml`)가 Mac · Windows 설치 파일을 만들어 Releases에 올려요.

| 파일 | 역할 |
|---|---|
| `main.js` | 떠 있는 창, 위치 기억, 메뉴 · 트레이, 자동 실행 |
| `collector.js` | Claude · Codex 기록을 읽어 한도 · 토큰 · 세션 상태 계산 |
| `claude-api.js` | Claude 계정에 남은 한도를 물어봄 |
| `claude-link.js` | Claude Code 상태줄 연결 / 해제 (백업 · 원래 상태줄 이어 실행) |
| `statusline.js` | Claude Code 상태줄. 받은 한도를 `~/.ai-usage-widget/claude-usage.json` 에 적음 |
| `renderer/` | 위젯 화면 |
